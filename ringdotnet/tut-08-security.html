Appendix

Quick introduction to Ring

Hashing and encryption

Checksums that fingerprint data, a key that proves a message was not changed, random tokens and real encryption with AES.

What you will learn#

  • the difference between hashing and encryption,
  • SHA-256 hashes,
  • HMAC and random tokens,
  • encrypting and decrypting text with AES.
Warning

This is a first look at the ideas, not a security course. For real systems use the standard libraries as shown here, never invent your own scheme, and keep keys out of your source code.

Hashing and encryption#

HashingEncryption
Directionone way: you cannot get the data backtwo ways: you can decrypt with the key
Result sizealways the same (SHA-256: 32 bytes)about the size of the data
Usecheck that data is the same; store passwordskeep data secret

A hash is a fingerprint. The same input always gives the same hash; a tiny change gives a completely different hash.

The program#

samples/UsingDotNet/tutorials/ch01_security.ring
# hashing and encryption basics - checksums, HMAC, random tokens, AES
load "dotnet.ring"

using {
	"System"
	"System.Security.Cryptography"
	"System.Text"
}

func main

	oConvert = new Convert()

	# A hash is a fingerprint of data: the same input always gives the same hash, you can not go back
	? "SHA-256 of 'abc'   : " + lower(oConvert.ToHexString(new SHA256().HashData("abc")))
	? "MD5 of 'abc'       : " + lower(oConvert.ToHexString(new MD5().HashData("abc"))) + "  (old: do not use it for security)"
	? "Changing one letter: " + left(lower(oConvert.ToHexString(new SHA256().HashData("abd"))),16) + "... is completely different"

	# HMAC: a hash with a secret key proves that a message was not changed
	oHmac = new HMACSHA256().@New([ :key = "secret key" ])          # the constructor that takes the key
	? nl + "HMAC             : " + left(lower(oConvert.ToHexString(oHmac.ComputeHash("message"))),32) + "..."

	# Random bytes for tokens: use RandomNumberGenerator, not Random
	? "Random token      : " + lower(oConvert.ToHexString(new RandomNumberGenerator().GetBytes(8)))

	# AES: encrypt and decrypt a text with a key
	oAes = new Aes().Create(NULL)
	oAes.GenerateKey()
	oAes.GenerateIV()
	cText = "Ring talks to .NET crypto"
	cCipher = oAes.CreateEncryptor(NULL).TransformFinalBlock(cText,0,len(cText))
	? nl + "Encrypted        : " + len(cCipher) + " bytes (the text had " + len(cText) + ")"
	? "Decrypted        : " + oAes.CreateDecryptor(NULL).TransformFinalBlock(cCipher,0,len(cCipher))

How it works#

SHA-256 and MD5#

new SHA256().HashData("abc") returns the hash bytes; Convert.ToHexString writes them as hexadecimal. SHA-256 is the modern standard. MD5 is broken for security: it is only fine for a quick checksum of a download.

Passwords#

Never store a password, and never store a plain hash of it either (attackers have tables of hashes of common passwords). A password needs a salted, slow hash (PBKDF2): a random salt so that two people with the same password get different hashes, and many rounds so that each guess is slow for an attacker. That needs a class whose constructor takes four values, and it is the subject of the tutorial Login, sessions and cookies in the chapter Security.

HMAC#

An HMAC is a hash that needs a secret key (new HMACSHA256().@New([ :key = "secret key" ]): the constructor that takes the key). If you and a server share the key, an HMAC on a message proves the message was not changed on the way.

Random tokens#

For secrets (session ids, reset links) use RandomNumberGenerator.GetBytes(n). The ordinary Random class is predictable and must not be used for secrets.

AES#

AES is the standard encryption. Aes.Create(NULL) makes an encryptor; GenerateKey() and GenerateIV() create a random key and initialization vector; CreateEncryptor(NULL).TransformFinalBlock(text, 0, length) encrypts, CreateDecryptor(NULL) decrypts. Anyone with the key and the IV can decrypt, so those must be kept safe and passed to the receiver separately from the data.

What you learned#

  • hashing is one way, encryption is two ways,
  • RandomNumberGenerator for secrets,
  • NULL selects a method's version without parameters.

Exercises#

  1. Write checksum(cFile) that returns the SHA-256 of a file's bytes (File.ReadAllBytes).
  2. Hash the same text with SHA-512 (new SHA512().HashData(...)) and compare the length of the result with SHA-256.
  3. Compute the HMAC of a message with two different keys. Are the results different?
  4. Encrypt a file's text with AES and write the cipher as Base64 text.
