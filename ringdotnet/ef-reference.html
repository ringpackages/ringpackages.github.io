Quick introduction to Ring

Entity Framework reference

Every method of RingDatabase and RingEntityDb, the schema format, the query specification, hooks and limits.

Schema format#

Ring
aSchema = [
	[ "TableName",
	  [ [ "Column", "type", isKey, [ ["option", value], ... ] ],  ... ],
	  [ ["tableOption", value], ... ]                                   # optional
	],
	...
]
PartValues
column typeint, long, double, decimal, string (or text), bool, datetime, bytes
isKey1 for a key column; several give a composite key. A single int/long key is generated by the database
column optionsrequired, nullable, unique, index, maxlength, default, references, ondelete, convert
table options["filter", condition] — a global query filter

Creating a database#

Ring
oDb = new RingDatabase(connection, aSchema)       # rows as [name, value] pairs
oDb = new RingEntityDb(connection, aSchema)       # real entity objects

The connection starts with the provider name (inmemory:, sqlserver:, postgres:, mysql:) or is a SQLite connection string.

Rows#

MethodReturns

byKey(table, key)the row, or "". The row is tracked: after raw SQL, call discard() to read the new values

update(table, key, values)1 when the row exists, else 0
remove(table, key)1 when the row existed, else 0

dbValue(row, column)a column of a row ("" for null)

MethodReturns

include(table, relatedTable)[[row, children-or-parent], ...] in two queries

Transactions and saving#

MethodDoes
begin(), commit(), rollback()a transaction; an error in commit() undoes everything
inTransaction()true while a transaction is active
autoSave(flag), save()batch changes; pendingChanges() lists them
discard()forget changes that were not saved
insertAsync, allAsync, whereAsync, countAsync, saveAsyncreturn a Task; dbWait(task) returns the result

Schema and migrations#

MethodDoes
migrate()creates missing tables, columns and indexes; returns the list of changes (SQLite)
apply(name, sql)runs a SQL change once; 1 when applied now, 0 when applied before
applied()names of the applied changes
columnInfo(table, column)[["name",..],["type",..],["key",..],["nullable",..],["required",..],["unique",..],["index",..],["maxlength",..]]

Hooks#

MethodDoes
onSaving(dnCallback("f"))f(aArgs) runs before changes are written; aArgs[1] is [[table, state, row], ...] (state: Added, Modified, Deleted). Return a text to cancel the save.
onSaved(dnCallback("f"))aArgs[1] is the number of rows written
onLog(dnCallback("f"))aArgs[1] is the text of each SQL command
pendingChanges()changes waiting to be saved: [[table, state, row], ...]

Other#

MethodDoes

MethodDoes
newEntity(table)a new object of the generated class
entityType(table)the .NET Type

Entities are plain DotNetObjects: oBook.getProp("Title"), oBook.setProp("Author", oAuthor); a collection navigation has getProp("Count") and toList().

Query specification#

A query is a list of [item, value] pairs:

ItemValue
wherea condition
orderby[[column, "asc"/"desc"], ...]
skip, takenumbers
select[column, ...] — keeps only those columns (RingDatabase)
include[navigation, ...] (RingEntityDb)
ignorefilters1 to ignore the table's global filter

A condition is [column, op, value] or a combination:

FormMeaning
["Age", ">", 30]comparison: = != < <= > >=
["Name", "contains", "an"]contains, startswith, endswith (text)
["City", "in", ["Cairo","Giza"]]membership
["Boss", "isnull"], ["Boss", "notnull"]null checks
["and", c1, c2, ...], ["or", c1, c2, ...], ["not", c]combinations

What is not supported#

  • Classes written in C# source — entity classes are generated from the schema.
  • Lambdas written by hand — queries are data.
  • Migrations that alter or drop columns (use execute or apply).
  • Hooks, converters and migrate() in RingEntityDb.
  • The SQL Server, PostgreSQL and MySQL providers have not been tested.
