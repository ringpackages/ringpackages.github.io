Quick introduction to Ring

RingDotNet

Call any .NET class from Ring with simple syntax. Build Windows Forms and WPF programs, web servers with ASP.NET Core, and databases with Entity Framework — all in Ring.

A first taste#

Ring
load "dotnet.ring"

using {
	"System"
	"System.Text"
}

oSB = new StringBuilder("Hello")
oSB.Append(", ").Append("Ring!")
? oSB.ToString()                   # Hello, Ring!
? oSB.Length                       # 12

? new Math().Max(3,9)              # 9
? new Math().Sqrt(144)             # 12

The classes are real Ring classes with the same method names as the .NET ones — like RingQt for Qt — so code completion, inheritance and ordinary Ring syntax just work. There is no eval and no string-based dispatch in your code.

How the package is organized#

FolderContents
bin/ring_dotnet.dll (the C extension), the managed bridge, ASP.NET and EF assemblies
libraries/dotnetlib/The Ring library: functions, the generated wrapper classes, GUI/WPF/web/data helpers
extensions/ringdotnet/C source of the extension and C# source of the bridge, web server and data layer
samples/UsingDotNet/tutorials/The program of each tutorial, named by chapter (ch01_first_look.ring...)
samples/UsingDotNet/introduction/Short console samples for each area
samples/UsingDotNet/Forms/ and Wpf/One small window program for each feature
samples/UsingDotNet/applications/Complete programs
samples/UsingDotNet/tests/Automated tests (run.sh)
tools/dotnettools/The class generators (gendotnet.ring, wrapassembly.ring), the manifest and the package script
tools/ring2exe/The library that ring2exe uses to give a program that uses .NET to other people
