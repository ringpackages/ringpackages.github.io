Class reference

Every .NET class that RingDotNet wraps: 5870 classes, structs, interfaces and enums in 116 namespaces. Each entry shows the .NET type, constructors, properties (as Ring attributes), methods (with the way to call them from Ring), and events.

Tip

Use the search box (/) to find a class by name. Load a namespace with using { "System.Text" }. How members are named in Ring: Core concepts.

Reading the Ring call column

  • Name(p1,p2): a method that has one form takes its parameters in order.
  • Name(NULL), Name(value), Name([ :param = … ]): a method with several overloads is one Ring method that takes one argument: NULL for no parameters, a value for one, or a list of named parameters.
  • callMethod("Name",[p1,p2]): the .NET name is one that every object already has in Ring (Release, IsNull, New, ToList...), so the method is called with callMethod.
  • A name with @ (@Next) is a .NET name that is a Ring keyword.
