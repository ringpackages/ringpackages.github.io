Appendix

Quick introduction to Ring

Tutorials

Step-by-step lessons for people who are new to .NET. Each one explains the ideas first, then builds a small program you can run, with the real output and screenshots.

How to use the tutorials#

Every tutorial has a program in the folder samples/UsingDotNet/tutorials. Read the explanation, run the program, change it, and do the exercises at the end. The programs are real: they are tested together with the rest of the package, so the output you see here is the output you will get.

Shell
cd samples/UsingDotNet/tutorials
ring ch01_first_look.ring            # a console tutorial
ring ch10_counter.ring              # a window
ring ch10_counter.ring --selftest   # the same program checks itself and closes
Tip

You do not need to know .NET to start. If you know Ring, you can follow every tutorial. The first two pages explain the .NET words that you will meet.

Note

The lessons about NuGet packages (the chapter Libraries and packages) run dotnet publish, so they need the .NET SDK and, the first time, the internet to get the packages.
