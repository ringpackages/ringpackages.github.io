Quick introduction to Ring

The .NET class library

A tour of the base class library as seen from Ring — dates, text, files, regex, compression, networking, cryptography, XML, JSON, data tables, reflection and big numbers. Every program on this page is a real sample and the output is real.

What is wrapped#

Every namespace below has generated classes, loaded on demand with using { "Name" }.

Other namespaces and any DLL: Your own assemblies.

Note

tools/dotnettools/auditcoverage.ring compares the public types of the installed .NET framework with the generated classes. Enums need no class (they are texts), delegates are callbacks (a delegate type has a class only when extension methods extend it), and the rest is listed by the tool, so you can see what is not wrapped yet.

Files, regular expressions and compression#

File, Directory, Path, StreamReader/StreamWriter, MemoryStream, Regex, GZipStream:

samples/UsingDotNet/introduction/test09_io_regex.ring
samples/UsingDotNet/introduction/test09_io_regex.ring
# Text files, compression and regular expressions
load "dotnet.ring"

using {
	"System"
	"System.IO"
	"System.IO.Compression"
	"System.Text.RegularExpressions"
}

oPath = new Path()
oFile = new File()
cDir = oPath.Combine([oPath.GetTempPath(),"ringdotnet_demo"])
new Directory().CreateDirectory(cDir)

# Text files
cLog = oPath.Combine([cDir,"log.txt"])
oWriter = new StreamWriter(cLog)
oWriter.WriteLine("2024-05-17 ERROR disk full")
oWriter.WriteLine("2024-05-18 INFO backup done")
oWriter.WriteLine("2024-06-01 ERROR network down")
oWriter.Close()
? "Lines in file : " + len(oFile.ReadAllLines(cLog).toList())
? "File size     : " + new FileInfo(cLog).Length + " bytes"

# Regular expressions: find the errors and their month
oRegex = new Regex("(?<month>\d{4}-\d{2})-\d{2} ERROR (?<what>.+)")
oMatches = oRegex.Matches(oFile.ReadAllText(cLog))
? "Errors found  : " + oMatches.Count
for nLoop = 0 to oMatches.Count - 1
	oMatch = oMatches.Item(nLoop)
	? "  " + oMatch.Groups.Item("month").Value + " -> " + trim(oMatch.Groups.Item("what").Value)
next
? "Cleaned       : " + new Regex("\s+").Replace([ :input = "too    many   spaces", :replacement = " " ])

# Compression
oPacked = new MemoryStream()
oGzip = new GZipStream(oPacked,"Compress")
cData = copy("Ring and .NET ",200)
oGzip.Write(cData,0,len(cData))
oGzip.Close()
? "GZip          : " + len(cData) + " -> " + len(oPacked.ToArray()) + " bytes"

cZip = oPath.Combine([oPath.GetTempPath(),"ringdotnet_demo.zip"])
if oFile.Exists(cZip) oFile.Delete(cZip) ok
new ZipFile().CreateFromDirectory([ :sourceDirectoryName = cDir, :destinationArchiveFileName = cZip ])
? "Zip created   : " + new FileInfo(cZip).Length + " bytes"

new Directory().Delete([ :path = cDir, :recursive = True ])
oFile.Delete(cZip)
Output

Networking#

Uri, IPAddress, Dns, HttpClient, WebUtility, Encoding — a program that does not need the internet to run:

samples/UsingDotNet/introduction/test12_network.ring
samples/UsingDotNet/introduction/test12_network.ring
# HTTP: a small web server and a web client in one program
load "dotnet.ring"

using {
	"System"
	"System.Text"
	"System.Net"
	"System.Net.Http"
	"System.Threading.Tasks"
}

# A tiny web server and client in one Ring program: .NET runs the requests on its thread pool,
# Ring waits for the tasks and answers
cPrefix = "http://localhost:" + (20000 + random(20000)) + "/"
oServer = new HttpListener()
oServer.Prefixes.Add(cPrefix)
oServer.Start()
? "Listening on " + cPrefix

oWaiting = oServer.GetContextAsync()
oClient = new HttpClient()
oRequest = oClient.GetStringAsync(cPrefix + "greet?name=Ring")

oWaiting.Wait(NULL)
oContext = oWaiting.getProp("Result")
? "Request        : " + oContext.Request.HttpMethod + " " + oContext.Request.Url.PathAndQuery
cReply = "Hello " + oContext.Request.QueryString.Item("name") + ", this is .NET speaking Ring!"
cBytes = new UTF8Encoding().GetBytes(cReply)
oContext.Response.OutputStream.Write(cBytes,0,len(cBytes))
oContext.Response.Close(NULL)

oRequest.Wait(NULL)
? "Response       : " + oRequest.Result
oServer.Stop()

# URL and address helpers
? "UrlEncode      : " + new WebUtility().UrlEncode("ring & .net = fun")
? "Loopback       : " + new IPAddress().Loopback.ToString()
? "Host name set  : " + (len(new Dns().GetHostName()) > 0)
Output
Listening on http://localhost:24995/
Request        : GET /greet?name=Ring
Response       : Hello Ring, this is .NET speaking Ring!
UrlEncode      : ring+%26+.net+%3D+fun
Loopback       : 127.0.0.1
Host name set  : 1
Tip

For HTTP requests use HttpClient. Methods that return a Task give you an object: call Wait() and read its property Result. A complete example is the self test of samples/UsingDotNet/applications/WebApi.

oAes = new Aes().Create(NULL)
oAes.GenerateKey()
oAes.GenerateIV()

# XML with XPath, JSON and data tables
load "dotnet.ring"

using {
	"System.Xml"
	"System.Text.Json"
	"System.Data"
}

# XML with XPath
oDoc = new XmlDocument()
oDoc.LoadXml("<shop><item price='3.5'>apple</item><item price='1.2'>fig</item><item price='9'>melon</item></shop>")
oItems = oDoc.SelectNodes("//item[@price > 2]")
? "Items over 2    : " + oItems.Count
for nLoop = 0 to oItems.Count - 1
	oItem = oItems.Item(nLoop)
	? "  " + oItem.InnerText + " costs " + oItem.GetAttribute("price")
next

# JSON: serialize Ring lists, read documents
oJson = new JsonSerializer()
? "Serialize       : " + oJson.Serialize([1,"two",[3,4]])
oDocument = new JsonDocument().Parse('{"user":"ring","langs":["ring","c","lua"],"stars":123}')
oRoot = oDocument.RootElement
? "user / stars    : " + oRoot.GetProperty("user").GetString() + " / " + oRoot.GetProperty("stars").GetInt32()
? "languages       : " + oRoot.GetProperty("langs").GetArrayLength()

# DataTable with SQL-like filtering and sorting
oTable = new DataTable()
oTable.Columns.Add([ :columnName = "Product", :type = "System.String" ])

Processes and threads#

Ring
using {
	"System.Diagnostics"
	"System.Threading.Tasks"
}

oInfo = new ProcessStartInfo() {
	FileName = "cmd"
	Arguments = "/c ver"
	RedirectStandardOutput = True
	UseShellExecute = False
	CreateNoWindow = True
}
oProcess = new Process().Start([ :startInfo = oInfo ])
? trim(oProcess.StandardOutput.ReadToEnd())
oProcess.WaitForExit(NULL)

oTask = new Task().Delay(30)                    # a Task: wait for it on the Ring thread
oTask.Wait(NULL)
? oTask.IsCompleted

oResult = new Task().FromResult("done")
? oResult.Result                                 # the Result of a Task<T>
Note

Ring code runs on the Ring thread only. A callback invoked from a pool thread prints a message on stderr instead. Use tasks for pure .NET work (HTTP, files, hashing), then Wait() for them on the Ring thread.
