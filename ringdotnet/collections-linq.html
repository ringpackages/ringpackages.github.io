Quick introduction to Ring

Collections & LINQ

Typed .NET collections with Ring syntax, indexers, copying to Ring lists, and LINQ queries over Ring lists or any .NET collection.

Typed collections#

The common closed generic collections have ready-made classes (using { "System.Collections.Generic" }):

Class.NET type
StringList, NumberList, ObjectListList<string>, List<double>, List<object>
StringDictionary, NumberDictionary, ObjectDictionaryDictionary<string, T>
StringSetHashSet<string>
StringQueue, StringStackQueue<string>, Stack<string>
Ring
using { "System.Collections.Generic" }

oList = new StringList()
oList.Add("banana") oList.Add("apple") oList.Add("cherry")
oList.Sort(NULL)
? oList.Count
aItems = oList.toList()                # toList() copies the collection to a Ring list
for cItem in aItems
	? cItem
next

oDict = new StringDictionary()
oDict.SetItem("two","2")               # indexers: Item(index) and SetItem(index, value)
? oDict.Item("two")
aResult = oDict.TryGetValue("three")   # out parameters come back as a list
? aResult[1]                           # 0

Tip

To add your own closed generic type, add a line to the :types list of its namespace in tools/dotnettools/dotnetmanifest.ring and run the generator (Class generator shows the line). Without a class, dnNewGeneric(...) gives you the object and callMethod works on it.

Sorting and searching with Ring code#

Methods that take a delegate (Predicate, Comparison, Action) accept dnCallback(...). The Ring code reads aDotNetArgs and sets xDotNetResult:

Ring
oList.FindAll(dnCallback("xDotNetResult = left(aDotNetArgs[1],1) = 'a'"))
oList.Sort([ :comparison = dnCallback("xDotNetResult = len(aDotNetArgs[1]) - len(aDotNetArgs[2])") ])
oList.@ForEach(dnCallback("? aDotNetArgs[1]"))

See Callbacks & events.

LINQ#

using { "System.Linq" } loads Enumerable and a fluent wrapper, dnQuery(...), that works on a Ring list or any .NET collection. The lambda is Ring code: it reads aDotNetArgs[1] and writes xDotNetResult.

Ring
using { "System.Linq" }

aSales = [120, 45, 300, 15, 210, 99, 81]

aTop = dnQuery(aSales).Where("xDotNetResult = aDotNetArgs[1] >= 100").OrderByDescending("xDotNetResult = aDotNetArgs[1]").Take(3).ToList()

? dnQuery(aSales).Count()
? dnQuery(aSales).Sum("")
? dnQuery(aSales).Average("")
? dnQuery(aSales).Max("")

# LINQ over Ring lists and strings: the conditions are Ring code
load "dotnet.ring"

using { "System.Linq" }

# Where, OrderBy, Count, Sum, Any ... take a condition written as Ring code (aDotNetArgs[1] is the item)
aSales = [120, 45.5, 300, 80, 15, 210, 99.9]

aBig = dnQuery(aSales).Where("xDotNetResult = aDotNetArgs[1] >= 100").OrderByDescending("xDotNetResult = aDotNetArgs[1]").ToList()
? "Sales >= 100 (high to low) : " + list2str(aBig)
oAll = dnQuery(aSales)
? "Count / Sum / Average     : " + oAll.Count() + " / " + oAll.Sum("") + " / " + oAll.Average("")
? "Min / Max                 : " + oAll.Min("") + " / " + oAll.Max("")
? "Any over 250 ?            : " + oAll.Any("xDotNetResult = aDotNetArgs[1] > 250")
? "All positive ?            : " + oAll.All("xDotNetResult = aDotNetArgs[1] > 0")

# Strings: select, distinct, order, skip/take
aNames = ["Ring","dotnet","Ring","linq","Lua","dotnet","Python"]
? "Distinct upper-cased      : " + list2str(dnQuery(aNames).Distinct().Select("xDotNetResult = upper(aDotNetArgs[1])").ToList())
? "Second to fourth by length: " + list2str(dnQuery(aNames).Distinct().OrderBy("xDotNetResult = len(aDotNetArgs[1])").Skip(1).Take(3).ToList())

# The raw Enumerable class: type arguments are inferred
oLinq = new Enumerable()
? "Enumerable.Last           : " + oLinq.Last(aNames)

The dnQuery methods#

GroupMethods
Filtering and projectionWhere(code), Select(code), SelectMany(code), TakeWhile(code), SkipWhile(code)
OrderingOrderBy(code), OrderByDescending(code), ThenBy(code), ThenByDescending(code), Reverse()
PagingTake(n), Skip(n), Distinct()
SetsConcat(other), Union(other), Intersect(other), Except(other)
ResultsToList(), Count(), CountWhere(code), First(), FirstWhere(code), Last(), ElementAt(n)
TestsAny(code), All(code), Contains(value)
AggregatesSum(code), Average(code), Min(code), Max(code) — an empty "" means the value itself
Note

The generic LINQ methods of Enumerable also work directly: the bridge infers the type arguments from the values you pass, and callbacks become Func<object, ...> delegates.
