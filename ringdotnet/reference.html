Quick introduction to Ring

Function index

Every function and class method of the Ring library, generated from the source files — with the comment that documents it.

This page is generated from the comments in libraries/dotnetlib/*.ring. Search it with the box at the top of the page.

Core (functions.ring)#

FunctionDescription
dnRequest(cOperation, aParameters)Send a request to the bridge: dnRequest("call", [oTarget, "Method", arg1, ...]), returns one value. The common answers (a text, a number, a yes/no, one object) are read directly, without making a list of items.
dnSend(cOperation, nHandle, cName, cArgs)The request of a generated method for a member of an object: the operation and the name are ready wire items ("s4:call", "s6:Append"), the handle is a number (0 is the null object) and the arguments are packed. It makes the same request text as dnRequest, without a list and a DotNetObject for the target (about 40% of the time of a call).
dnExchange(cRequest)Send a request text to the bridge and read the answer
dnFinish(cResponse)The answer of the bridge (one item, or a list of items) as a Ring value
dnAnswer(xAnswer)The answer of a typed call (dotnet_getp, dotnet_callt, dotnet_calltd): a number or a text as it is; anything else (a null text, an object, from the generic request that the extension made) comes as the marker list that dnFinish reads. A call to this function costs less than the same statements in the generated method.
dnFlush()The handles of the objects that Ring freed are released in groups (the next .NET call does it when 32 are waiting). dnFlush() releases them now. Ring frees an object a little after the last variable that held it is gone; callgc() (called in the same function) makes it free the objects at once. So to let go of a big object now (or before you look at the memory of .NET with GC.GetTotalMemory) write: oBig = NULL callgc() dnFlush()
dnHandleCount()The number of .NET objects that Ring holds now (handles in the table of the bridge): a test of the release of handles compares it before and after the objects were dropped (call callgc() and dnFlush() first)
dnVersion()Version of the .NET runtime that is hosted in this process
dnLoad(cPath)Load an assembly (.dll) from a path, returns the assembly name
dnLoadName(cName)Load an assembly by name (for example "System.Xml")
dnType(cTypeName)Get a type (to call its static members), for example dnType("System.Math")
dnNew(cTypeName, aParameters)Create a .NET object: dnNew("System.Text.StringBuilder", ["Hello"]) The arguments can be named: dnNew("StringBuilder",[ :value = "Hello", :capacity = 64 ]) chooses the constructor by the parameter names (the order does not matter). The class is a full .NET type name or the name of a generated Ring class (see dnImport)
dnStatic(cTypeName, cMethod, aParameters)Call a static method: dnStatic("System.Math", "Max", [3, 9])
dnCallNamed(nTarget, cMethod, aParameters)A call by the name of the method (callMethod, dnStatic): the extension packs the arguments and reads any answer. nTarget is the handle of the object or of the type.
dnObj(xInfo)The answer of dotnet_callo (a call that returns an object): the extension answers the text "<handle>|<type>|<base type>..." and the Ring function wraps it as the generated class of the type; null is 0; any other answer is the list [1, answer] that dnFinish reads.
dnMakePrototype(cFactory)Make the ready object of the class of a factory function (no handle, no guard) once, and keep it in aDotNetPrototypes
dnAny(aAnswer)The answer of dotnet_calla (any answer): the extension answers a text, a number or a yes/no itself and an object as the list [2, "<handle>|<type>..."]
dnTypeHandle(cTypeName)The handle of the type object of a type name, made once (the generated static methods pass it as a number: returning the cached type object itself would copy it at every call)
dnTypeItem(cTypeName)The wire item of a type (its handle), made once for each type name
dnNewHandle(cOperation, cTypeName, cArgs)Make an object and read its handle from the answer: the answer is a number, so the object is not wrapped for Ring (0: a value such as an Int32 has no object, its class is used for static members)
dnIsNamed(aValue)True for a list of [name, value] pairs, the way Ring passes named arguments: [ :server = "x", :port = 80 ] ([] too)
dnCreateNamed(cTypeName, aNamed)The handle of an object created with named arguments (used by generated code)
dnDescribe(cTypeName)Public API of a type (used by tools/dotnettools/gendotnet.ring)
dnCallback(cCode)Ring code callable from .NET: dnCallback("? aDotNetArgs[1]") or dnCallback("myfunc"), then pass it where a delegate is expected. Code in a text reads the arguments from aDotNetArgs and sets xDotNetResult. The NAME of a function is called with the list of the arguments (func myfunc aArgs) and its return value is the result. The code is compiled once into a function (the same code gives the same function). A callback runs on the Ring thread, while a call from Ring is running (see the page "Rules and limits").
dnUseDesktop()Use Windows Forms / WPF (adds the Windows Desktop runtime). Call it before any other .NET call.
dnImport(cNamespace)Load the generated Ring classes of a .NET namespace: dnImport("System.IO"). using { "System.IO" } calls it for each name.
dnImportFrom(cFolder, cNamespace)Load classes generated by tools/dotnettools/wrapassembly.ring for your own assembly: dnImportFrom("myclasses/","MyCompany.Tools")
dnGenericName(cType, aArguments)Name of a closed generic type: dnGenericName("System.Collections.Generic.List",["System.Int32"])
dnBox(cType, nValue)A value of an exact .NET type for a parameter of type object: a whole number that goes to an object is an Int32 (Ring has one kind of number), so dnBox("System.Double",10) is the Double 10, dnBox("System.Int64",5) the Int64 5 (also Single, Decimal, Byte ...)
dnNewGeneric(cType, aArguments, aParameters)Create an object of a generic type without a generated class (a DotNetObject: use callMethod/getProp)
dnAssert(cName, xActual, xExpected)Simple test helpers: dnAssert("name",actual,expected) ... dnTestSummary(). Numbers are compared with a small tolerance, texts exactly (binary data too: a text can hold any byte). A failure prints one line: FAIL: name expected <..> got <..>
dnTestSummary()Print "TESTS: n passed, m failed" and return the number of failures
dnRegisterClass(cType, cClass, nInit)Register a generated class: objects of this .NET type are returned as instances of the Ring class
dnLoadClassIndex()The index of the generated classes ([type, namespace] pairs) is a file of about six thousand entries: it is loaded when it is first needed (an object comes back whose class is not loaded yet), not when a program starts
dnAddClassIndex(aItems)Called by the index files that the generators write: dnAddClassIndex([ ["System.IO.File","System.IO"], ... ])
dnBuildIndexMap()The index of the generated classes as a hash table (type --> namespace); built once, when it is first needed
dnWrapInto(cInfo)The same, but the object is left in the global oDotNetNew (returning it would copy it once more: a class can have 100 attributes)
dnFindFactory(cChain)The factory function for a chain "type|base type|..." (the most specific type first: a type that is not imported yet is imported on demand before a less specific one is used), or "-" when no class is known
dnClassOfType(cType)The Ring class of a .NET type name: the namespace of the type is imported when it is not loaded yet; "" when there is no class
dnCombinedFactory(aClasses)The factory of a combined class. Ring has one parent for a class, and an object that is two interfaces at once (IElement and IContainer: Text() is a method of the second) needs the members of both, so a class is made once for the list of classes: it derives from the first, and the methods of the others are merged into it. A wrapper method does nothing but send the name of its method to the bridge, so a method works on any object that has it, whichever interface it was made for.
dnMakeMix(cMix, aClasses)
dnClassAttributes(cClass)The attributes of a generated class (the names in lower case)
dnMergeClass(cDestination, cClass)Merge the methods of a class, then of the class it derives from..., into another class (the classes of DotNetObject are in every class already)
dnEnsureExt(cClass)The static class with the extension methods that a generated method calls: its assembly is loaded by the bridge the first time
dnNull()The .NET null: oPictureBox.Image = dnNull()
dnIsNull(xValue)Is the value the .NET null? True for a null object, false for every other value (a number, a text, a list, an object that is not null)
dnBuffer(xSizeOrBytes)A byte buffer that .NET can fill: oBuffer = dnBuffer(1024) makes a byte[] of 1024 bytes, dnBuffer("bytes") one with the bytes of a text. A byte[] that .NET returns is a Ring text (a copy), and a Ring text passed in is a new array, so a method that FILLS an array (Stream.Read, Socket.Receive...) needs this object: pass it as the byte[] parameter and read what was written with dnBufferBytes. n = oStream.Read(oBuffer,0,1024) cBytes = dnBufferBytes(oBuffer,n)
dnBufferBytes(oBuffer, nCount)The first nCount bytes of a buffer as a Ring text (use the number that Read or Receive returned; dnBufferSize(oBuffer) for all of them)
dnBufferSize(oBuffer)The size of a buffer in bytes
dnUseWeb()Use ASP.NET Core (adds the ASP.NET runtime and loads the web server of RingDotNet). Call it before any other .NET call.
dnUseAll()Windows Forms / WPF and ASP.NET Core together (using { } starts it when the names of both are used). Call it before any other .NET call.
dnUseData()Use Entity Framework Core with SQLite (loads the data assembly of RingDotNet and its packages)
dnLoadSelfTest()The checks of a program with a window are kept in a file of their own, so the sample stays a clean program: next to the program, the file selftest/<name of the program>.ring defines func selfTest(). When the program runs with --selftest, uiRun() (or wpfRun()) loads that file, runs selfTest() once the window is shown, closes the window and prints the result. Returns True when such a file was loaded.

FunctionDescription

DotNetObject.isNull()True for the null reference
DotNetObject.callMethod(cMethod, aParameters)Call a method by its name: oObject.callMethod("Append", ["text"]). It works for every .NET object, also when no class was generated.
DotNetObject.callGeneric(cMethod, aTypeArguments, aParameters)Call a generic method whose type argument only its result shows (JsonConvert.DeserializeObject<T>(json)): the type arguments are a list of type names, then the arguments: oType.callGeneric("DeserializeObject",["System.Collections.Generic.List`1[[System.String]]"],[cJson])
DotNetObject.convertTo(cType)The conversion of the object to a .NET type with the operators op_Implicit / op_Explicit (the cast of C#): oToken.convertTo("System.String")
DotNetObject.getProp(cMember)Read a property or a field
DotNetObject.setProp(cMember, xValue)Write a property or a field
DotNetObject.toString()ToString() of the object
DotNetObject.typeName()Full name of the .NET type
DotNetObject.toList()Copy the items of an array or collection to a Ring list
DotNetObject.asyncEnumerator()An IAsyncEnumerable (a method that returns one has no await foreach in Ring): toList() reads all the items. One item at a time: oEnum = oStream.asyncEnumerator() while oEnum.asyncNext() ? oEnum.Current end oEnum.asyncDispose()
DotNetObject.asyncNext()Wait for the next item of an async enumerator: true when there is one (it is Current), false at the end
DotNetObject.asyncDispose()End an async enumerator (toList does it by itself)
DotNetObject.release()Release the reference kept by the bridge now (the object is not used after this). Ring releases it by itself when the last variable that holds the object is gone (see oDotNetGuard); this is only needed to let go of a big object at once.
DotNetOwned.init(pHandle)a .NET object that Ring owns: pHandle is its handle, which is released when the Ring object is dropped
DotNetCallback.init(pCode)keep the Ring code (a text of code or the name of a function) that .NET runs when it calls the delegate

FunctionDescription

DotNetQuery.Where(cCode)the items for which the code gives true

DotNetQuery.SkipWhile(cCode)leave out the items from the start, while the code gives true
DotNetQuery.Take(nCount)the first nCount items
DotNetQuery.Skip(nCount)leave out the first nCount items
DotNetQuery.Distinct()every value once
DotNetQuery.Reverse()the items in the opposite order
DotNetQuery.Concat(oOther)the items followed by the items of oOther (a query, a list or a .NET collection)
DotNetQuery.Union(oOther)the values of both sources, every value once
DotNetQuery.Intersect(oOther)the values that both sources have
DotNetQuery.Except(oOther)the values of this source that oOther does not have
DotNetQuery.ToList()run the query: the result as a Ring list
DotNetQuery.Count()the number of items
DotNetQuery.CountWhere(cCode)the number of items for which the code gives true
DotNetQuery.Any(cCode)1 when the code gives true for at least one item
DotNetQuery.All(cCode)1 when the code gives true for every item
DotNetQuery.Contains(xValue)1 when the source has the value xValue
DotNetQuery.First()the first item (an error when there is none)

DotNetQuery.Last()the last item (an error when there is none)
DotNetQuery.ElementAt(nIndex)the item at the zero-based position nIndex
DotNetQuery.Sum(cCode)Sum, Min, Max and Average are computed on the selected values (cCode = "" for the items themselves)
DotNetQuery.Average(cCode)the average of the selected values (cCode = "" for the items themselves)
DotNetQuery.Min(cCode)the smallest of the selected values (cCode = "" for the items themselves)
DotNetQuery.Max(cCode)the largest of the selected values (cCode = "" for the items themselves)
DotNetQuery.dnSelected(cCode)the values that the code selects (the items themselves for ""), as a Ring list: used by Sum, Average, Min and Max

Generated classes#

The wrapper classes are generated; there are two files for each namespace in libraries/dotnetlib/generated/ (a loader and the classes). The members of a class are the members of the .NET class (see the .NET documentation), named by the rules. To see the Ring name of a method, open its class file or call dnDescribe("Namespace.Type").
